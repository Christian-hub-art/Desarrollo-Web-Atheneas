# Athenia

Proyecto de página web sobre un universo ficticio de personajes heroicos y malvados, creado como ejercicio de desarrollo web.

## Descripción

Athenia es una landing page y galería de personajes diseñada con HTML, CSS y JavaScript. La página presenta una introducción al mundo de Aetheria, una sección de personajes con tarjetas informativas y elementos interactivos para explorar el contenido.

## Características

- Página de bienvenida con diseño visual atractivo.
- Galería de personajes con información de cada uno.
- Carrusel de imágenes con Bootstrap.
- Filtros para mostrar solo héroes o villanos.
- Botón de favorito para cada personaje.
- Frase del día consumida desde una API externa.
- Diseño responsivo y estilo temático oscuro.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Estructura del proyecto

- `index.html` — página principal de inicio.
- `personajes.html` — galería de personajes.
- `estilos.css` — estilos y diseño visual.
- `script.js` — interacciones dinámicas.
- `Heroe1.jpg`, `Heroe 2.jpeg`, `Villano1.jpg`, `Villano 3.jpeg` — imágenes de personajes.

## Cómo ejecutarlo

1. Descarga o clona este proyecto.
2. Abre la carpeta `Athenia`.
3. Ejecuta el archivo `index.html` en tu navegador.

También puedes usar una extensión como Live Server en VS Code para una mejor experiencia durante el desarrollo.

## Objetivo del proyecto

Este sitio fue desarrollado para presentar una pequeña historia y una galería de personajes con estilo visual, interactividad y datos básicos de fuerza, defensa y velocidad.

## Nota

Es un proyecto estático, por lo que no requiere backend ni base de datos para funcionar correctamente.
